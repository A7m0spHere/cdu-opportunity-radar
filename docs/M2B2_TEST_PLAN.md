## 失败片段的安全边界

新增诊断捕获默认关闭，只在本计划显式启用。非 200 响应最多读 8192 字节，保存受限参数名（若服务给出）与脱敏结构；正常响应仍受 1 MiB 限制。失败结构片段最多 384 字符，脱敏 payload 投影片段最多 4096 字符，最多 100 条文本长度/哈希元数据。字段名和枚举只保留固定契约白名单，任意文本、个人标识和未知数字被移除；没有敏感请求头、完整模型响应、原始正文或推理文本。

片段明确标识 `lossy=true`、`redacted-failure-v1`。它们用于复现错误阶段和检查结构/类型，**不保证逐字重放原响应或恢复语义**；必须使用保存的原错误路径、行列、计数、摘要和输入版本。不能把脱敏占位符当模型原话或补造原始引用。原始输入检查也纳入 Provider 内的诊断，避免把发出前生成的脱敏标记当事实后才在外层无信息地失败。

真实诊断和结果仅在忽略的 `data/` 本地保留。Git 只包含工具、合成测试和此计划，不包含真实响应/标签/原文。公开报告采用数量、阶段、ID 和必要聚合信息。
