## 限制与交接

本轮在 Windows 验证 OS 锁和真实环回 HTTP；Linux systemd、反向代理/TLS、实际插件和测试群推送**未执行**。部署要求本地 SQLite 回滚日志模式、正确系统时间、可靠本地磁盘、服务账号数据库/状态目录权限；不支持 WAL，不能用普通静态服务器或代理旧缓存绕过守门。

493 项通过不代表实际 AstrBot 联调通过。插件去重库丢失或历史上限可能重放，空 Feed 可能无法初始化，已发送消息不可撤回；请求验证前已在传输中的内容无法追回。短暂 503 是保守暂停，不保证零延迟或任意客户端永不重复。
