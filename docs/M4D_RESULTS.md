## 体验与安全修复

1. 系统采集/数据核验时间补全年份，避免 2024 年原文与 2026 年采集时间只看月日而混淆。
2. 新入口拒绝跨站数据请求，同时允许从外部链接顶层打开公开首页；实际桌面浏览器首次进入曾触发过严拒绝，已修复并保留 API 拒绝回归。
3. Windows 维护页 HTTP 200 不再归为新模板解析待接入；不保留旧正文为有效机会。
4. 独立入口仅转发固定环回上游，校验公开契约/字段，不转发 Cookie/Authorization，不使用旧 XML 回退；原 RSS 监听仍拒绝 LAN/0.0.0.0。

现场操作方案、安全边界和用户手动启动/检查/停止命令见 [LAN_PREVIEW.md](LAN_PREVIEW.md)。本轮只运行 `--check-only` 和 127.0.0.1 转发测试，没有运行 `--enable-lan`。
