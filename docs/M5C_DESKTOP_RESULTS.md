## 复现

在项目根目录，选择尚不存在的新验收目录，使用当前已安装 wheel 的 Python：

```powershell
.\artifacts\rss-v1-wheel-check\venv\Scripts\python.exe -I scripts/m5c_desktop_acceptance.py --source-db artifacts/m4d-live/notices.sqlite3 --directory artifacts/m5c-desktop-new --as-of 2026-10-15T20:14:25.061261+08:00 --serve
```

不传 `--serve` 时完成机器检查后自动停止。传入时从新目录 `preview.json` 读取本机地址；私有 `mode` 文件只支持 `normal`、`timeout`、`upstream_stopped`、`source_unavailable`，用于该 runner 的故障走查，生产 HTTP 无此入口。向该目录新建 `stop` 文件可正常停止并写出端口关闭结果。源库必须存在，脚本不会新建替代源库，不覆盖已有验收目录。
