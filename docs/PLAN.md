## M0 原始计划与结果

目标：从两个真实成都大学官方栏目采集原始通知，写入 SQLite，并生成本地 RSS 2.0 技术验证 Feed。

1. 调查（2026-10-13）：检查空工作目录及 Python 环境；读取官网院系设置，登记官网链接；实际检查两个栏目、正文和 robots.txt。
2. 实现：Python 3.12 虚拟环境；httpx + BeautifulSoup 的同步低频请求；两个栏目适配器与共享正文解析；SQLite URL 唯一约束、来源关联、内容哈希更新；本地 collect / export-rss CLI。
3. 离线验证：保存经裁剪的真实 HTML 样本及出处；pytest 覆盖结构变化、请求失败隔离、幂等与更新、日期语义及 RSS 中文转义。
4. 集成验证：每栏目限制少量文章，独立于 pytest；核对标题、链接、日期、正文；重复运行核对记录数；保存可复核的结果到 docs/VALIDATION.md。

边界：M0 不做 AI 判断、赛事级去重、所有学院适配、AstrBot/QQ 配置、服务端公开 Feed 或生产部署。不自动提交或推送 Git。栏目包含获奖新闻、公示等，Feed 不等于有效报名机会清单。

后续优先级：规则筛选和日期/资格抽取 → 小样本人工评估 → 更多模板适配与分页增量 → 赛事级转载去重 → 经过审核后再接入订阅客户端。
