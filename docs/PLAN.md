# M0 实施计划

目标：从两个真实成都大学官方栏目采集原始通知，写入 SQLite，并生成本地 RSS 2.0 技术验证 Feed。

1. 调查（2026-10-13）：检查空工作目录及 Python 环境；读取官网院系设置，登记官网链接；实际检查两个栏目、正文和 robots.txt。
2. 实现：Python 3.12 虚拟环境；httpx + BeautifulSoup 的同步低频请求；两个栏目适配器与共享正文解析；SQLite URL 唯一约束、来源关联、内容哈希更新；本地 collect / export-rss CLI。
3. 离线验证：保存经裁剪的真实 HTML 样本及出处；pytest 覆盖结构变化、请求失败隔离、幂等与更新、日期语义及 RSS 中文转义。
4. 集成验证：每栏目限制少量文章，独立于 pytest；核对标题、链接、日期、正文；重复运行核对记录数；保存可复核的结果到 docs/VALIDATION.md。

边界：M0 不做 AI 判断、赛事级去重、所有学院适配、AstrBot/QQ 配置、服务端公开 Feed 或生产部署。不自动提交或推送 Git。栏目包含获奖新闻、公示等，Feed 不等于有效报名机会清单。

后续优先级：规则筛选和日期/资格抽取 → 小样本人工评估 → 更多模板适配与分页增量 → 赛事级转载去重 → 经过审核后再接入订阅客户端。

## 本轮结果

已实现并验证：两种真实栏目模板、低频 HTTP 请求及日志、SQLite 幂等/更新/来源关联、RSS 2.0 本地导出、49 项离线测试。计算机学院和商学院各实际采集 3 篇，重复采集保持 6 篇，RSS 阅读器解析通过；详见 `VALIDATION.md`。

未完成：优先指定的创新创业学院本机访问持续失败，已登记 failed 并记录请求错误，没有猜测适配器。官网目录已登记 30 个条目，其余未接入；本轮没有宣称全校覆盖。

## 下一轮需求（按优先级）

1. 重验创新创业学院网络连接；取得真实 HTML 后实现并测试该列表及跨学院原文路由，网络恢复前不标记 verified。
2. 建立少量人工标注样本，先用可解释规则区分报名通知、获奖新闻、公示；提取资格和截止日期、识别过期信息，覆盖非编程和跨学科活动。
3. 适配更多实际观察到的学院模板；在严格数量限制内引入分页和增量策略，补充流式响应大小限制及 robots 复杂规则测试。
4. 以已收集样本验证转载的赛事级去重和 URL 规范化，避免将不同轮次或不同校内选拔通知误合并。
5. 在 Linux 上复现安装和采集，补充 CI 并选定开源许可证；通过人工确认 Feed 有效性后再验证订阅客户端，不直接接入生产 QQ 群。

AI 分析、外部来源和正式推送在后续里程碑另行明确，不纳入本轮实现。
