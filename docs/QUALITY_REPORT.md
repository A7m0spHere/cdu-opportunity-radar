# 离线只读质量报告（Issue #7）

`quality-report` 读取一个一致的 SQLite 快照，输出 Markdown 或 JSON。它不调用 `Store` 初始化、不迁移或写入数据库、不联网、不调用模型，也不修改人工标签或审批记录。当前支持项目使用的回滚日志模式；WAL 和缺少自动发布表的旧库明确拒绝，不用 `immutable=1` 忽略实时 WAL。

```powershell
.\.venv\Scripts\python.exe -m cdu_radar quality-report --db artifacts/m4d-live/notices.sqlite3 --as-of 2026-10-15T20:14:25.061261+08:00 --data-mode offline_replay
.\.venv\Scripts\python.exe -m cdu_radar quality-report --db artifacts/m4d-live/notices.sqlite3 --as-of 2026-10-15T20:14:25.061261+08:00 --window-hours 72 --data-mode offline_replay --format json --output artifacts/m4d-quality-new.json
```

省略 `--as-of` 使用当前北京时间；默认窗口 72 小时，区间为 `[as_of - window_hours, as_of)`。默认写 stdout，指定输出必须是新文件且父目录已存在，拒绝覆盖数据库、侧文件、已有文件或符号链接。缺库、损坏、缺表、锁定或不支持的日志模式返回非零错误，不伪装成空库。

输出路径保留原始末级名称再以排他创建写入，不先跟随悬空符号链接；Windows 数据库及侧文件按本机路径大小写规则比较。不会因为 `-JOURNAL` 的大小写变化绕过侧文件保护。

## 指标口径

| 指标 | 分母与定义 |
| --- | --- |
| 新发现独立原文 | 首次 `discovered_at` 落在窗口内的最终官方 URL；跨来源转载只算一次 |
| 最近实质更新原文 | 最后 `updated_at` 落在窗口内且晚于首次发现的独立原文；数据库没有完整逐次修订历史，不能宣称是历史更新事件总数 |
| 采集事件 | 按 `collection_runs.finished_at` 落入窗口求和；新增、更新、unchanged、失败、重复及解析失败分别列出，重复尝试不等于新文章 |
| 质量合格 | 复用当前 `AutoRepository.feed_plan` 的可信来源、原文哈希、72 小时核验、撤回和日期门禁；以库内全部独立原文为基数 |
| 非历史参与候选 | 确定性规则识别为竞赛/活动/科研招募等、非历史、非其他通知、未判不符合资格；另排除标题公示和原文明示的纯非学生对象，不是人工真值 |
| 可能仍可参与 | 原发布门禁的 `possible` 状态；不因这个状态单独认定报名已开放 |
| 正文开放证据 | 候选且 possible，正文有未被否定的开放用语/已到报名开始日期、本科生资格及参与对象；保留引用和截止证据。不保证附件细则及每个人的完整资格 |
| 未知/历史/截止/行政 | 报名未知、历史、closed、规则行政或标题公示分别计数；另列明确非学生对象、规则类型未知、资格未知。这些维度可以重叠，不能相加 |
| 来源覆盖 | 当前配置已实现并验证的栏目数 / 候选栏目登记数；另列登记项总数、去重候选 URL 数和库内实际观察来源数。不同来源可关联同一原文，来源计数不能加成全局总数 |
| 来源健康 | 仅以当前已实现来源为分母，列从未在本库采集、最近尝试是否失败、最后完整成功采集是否缺失/未来/超过 72 小时；成功时间只取 collection_runs，不用目录预置的 verified 时间冒充本库采集成功 |

`snapshot` 是参考时间的全库资格快照；`window.qualified_cohort` 只看窗口内新发现或最后更新的条目。数据只有最后更新状态，不能据此完整重建任意过去时刻的数据库。`offline_replay` 明确表示旧数据回放，`mixed_baseline_and_live` 表示历史基准与新增实采混合；二者都不能冒充对全部原文的当前重新联网核验。

来源发布日期目前仅保存到日，没有来源时分秒/时区。因此**精确收录时延的 min/median/max 为 null**，并报告不可计算篇数；另列来源日期与首次采集日的日历日差，不能称为精确小时延迟。缺日期、采集时间或日期倒置分别计数，不以采集时间填补来源时间。

报告携带规则分析器版本、报告策略版本和实现文件 SHA-256，便于对照不同口径。报告不会把旧人工标签、预测或审核状态混成新的事实。

开放用语必须直接陈述报名开放；“即日起咨询”、被否定或未经确认的“正在报名”不算证据。原文明示报名开放待定、暂停或另行通知时，不用一个已到的开始日期覆盖该限制。“教师除外”“不要求教师身份”等否定对象限制也不能被当成纯教师/工作人员对象。
