# #27 本机修复与候选准备（2026-10-23）

公告：[GHSA-6q48-6c7w-9gw2](https://github.com/advisories/GHSA-6q48-6c7w-9gw2)。开始时锁文件与本机环境均为 certifi 2026.7.22；修复为精确 2026.10.19，wheel 亦声明最低安全版本。构建工具、审计工具分别固定版本，并升级实际开发环境的 pip/certifi。

发现的实际问题不止版本：进程 SSL_CERT_FILE 引用旧 CA 包，普通 HTTPX 默认上下文仍包含 emSign ECC Root CA - G3。应用现显式使用 certifi 修复包，采集、DNS 覆盖和模型客户端不继承该覆盖；保留代理、证书和主机名验证。诊断脚本同样采用项目上下文。全局 CA 文件和环境变量未改。

环境预检报告区分 ambient HTTPX 和应用实际上下文：本机 ambient 仍信任受影响根，因此不能称为整个系统环境已修复。部署单元清除自身 CA 覆盖，应用仍显式绑定修复包。预检不读取凭证、不发网络或模型请求。

没有增加官网采集轮次或付费模型请求；仅有依赖/公告查询和一条公开 PyPI 元数据 TLS 验证。模型缓存可按原输入、模型及 Prompt/Schema 零请求重验，旧账本与人工标签保留。

候选版本为 0.2.0rc1。完整提交范围、source tree、wheel 与依赖摘要、安装后验证等记录在 `artifacts/release-0.2.0rc1/` 的最终 manifest。实际部署步骤和回滚限制见 [发布候选说明](RELEASE_0_2_0_RC1.md)。
