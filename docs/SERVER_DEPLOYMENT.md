## 几天后验收与启停

先打开网页切换“本科生实用/全部原文”和“重要精选”，核对来源日期、原文链接及筛选结果；再看下列状态与最近快照：

```bash
sudo systemctl status cdu-radar.service cdu-radar-observe.timer --no-pager
sudo systemctl show cdu-radar.service -p NRestarts -p MemoryCurrent -p ActiveEnterTimestamp
sudo journalctl -u cdu-radar.service --since '48 hours ago' --no-pager
sudo systemctl start cdu-radar-observe.service
sudo ls -lt /var/log/cdu-radar/observations/*/
```

以连续经过时间、来源成功/失败与健康年龄、复查积压、模型失败/用量、分类覆盖、同范围 RSS 一致性和资源变化共同判断；不能只看网页能打开。人工分类效果仍需后续抽查。

停止本实例：先 `sudo systemctl stop cdu-radar-observe.timer`，再 `sudo systemctl stop cdu-radar.service`。恢复使用对应的 `start`；如需阻止开机启动再执行 `disable`。仅操作这两个本项目单元，不重启既有容器。

备份或回滚前停止本项目写者，保留最新数据库及账本；按发布说明恢复到新目录，不用旧备份覆盖新增用量。原本机数据、此次迁移副本和旧运行时均保留。
