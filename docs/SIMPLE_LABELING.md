# 简单标注：先看 10 篇就好

不用填 CSV，也不用输入英文。

1. 双击标注包里的 **开始标注.html**。每次只显示一篇原文。
2. 选 4 个答案，再点原文中的一两句话作为依据。拿不准就选“看不出来”或“分不清”，也可以先跳过。
3. 勾选本人核对，点“保存，下一篇”。先做 10 篇就可以停，点 **导出我的标注**，把下载的 JSON 文件交回即可。

页面会在当前浏览器暂存。换设备或担心丢失时，先导出；之后用“恢复进度”选择这个 JSON 就能继续。

## 四个问题怎么选

| 问题 | 按什么判断 |
| --- | --- |
| 值得放进重要精选吗？ | 是否影响学生权益、学习安排、安全服务，或提供有用的参与信息；不只看个人兴趣。选“值得”后再点一个主要原因。 |
| 对本科生有实际用处吗？ | 是否有本科生能用到的信息；纯教师事务、普通工作回顾通常不属于这一项。 |
| 有没有报名、办理或参与的事项？ | 正文是否提到了实际事项或入口。不要求今天仍能报名，也不代表你本人符合资格。 |
| 这篇主要是什么？ | 通知、新闻、活动、竞赛或科研。分不清就直接选“分不清”。 |

共同依据可以选多句，标题也能选。它们用于说明这篇的判断，不需要手工复制粘贴。补充分类和原因可以不填；没有填写的维度保持未标注。

材料冻结于 2026-10-18，存在历史信息。按页内原文判断即可，不用搜索更多材料。这里只收集评测标签，不是批准发布。

## 维护者：生成、回收与验证

现有 50 篇冻结数据和 development/holdout 划分保持不变；标注页不展示模型预测、规则标签或划分。默认先显示 10 篇，可以分批增加。页面没有预填答案，只有用户逐篇确认并保存后才形成已确认记录。

```powershell
.\.venv\Scripts\python.exe scripts/simple_quality_review.py page --directory artifacts/m10-quality-20261021 --output artifacts/my-simple-review/开始标注.html

.\.venv\Scripts\python.exe scripts/simple_quality_review.py convert --directory artifacts/m10-quality-20261021 --input 下载的标注.json --output artifacts/my-simple-review/filled-review.csv
```

生成前先建立输出目录。转换仅处理逐篇明确确认的记录，未确认草稿不导入；校验样本身份和原文引用，保留未知语义。正例的入选原因来自用户选择，技术列由程序恢复；没有选择的分档、事务领域和主题不会自动推断。原有 `quality-benchmark import/evaluate` 可直接消费生成的 CSV，见 [完整评测指南](QUALITY_BENCHMARK.md)。

只有标注者本人能确认 human 标签。软件测试必须用 `page --synthetic`，转换也必须显式加 `--allow-synthetic`；输出标记为 synthetic，默认评测不计为人类标签。页面和转换器不能证明实际点击者的身份，不自动填写真实标签或将模型预测变为真值。

本轮后端及既有评测回归 22 项通过，包含源正文不能逃逸嵌入 JSON 的检查。另以无浏览器 DOM 测试检查空白答案、确认门槛、未知、依据选择、改动后重新确认、下一篇空白、本地保存和 JSON 导出，并将 synthetic 导出转换为既有 CSV 格式。没有模型调用、官网请求或真实人工标签产生。Chrome 控制未连接，内置浏览器策略禁止 file URL；本轮未完成实际浏览器渲染/尺寸检查，不能将 DOM 合约检查称作实机 UI 验收。
