# 验证索引

本文件是**验证索引**，不是验证记录：明细在各阶段报告，这里只回答“什么被验证过、属于哪类证据、证据在哪”。历史明细（M0–M2-B.1，止于 2026-10-14）已归档到 [VALIDATION_M0_M2](archive/VALIDATION_M0_M2.md)（内容逐字保留，仅链接路径按归档位置更新）。

## 证据分级

| 类别 | 能证明什么 | 不能证明什么 |
| --- | --- | --- |
| 离线模拟/离线测试 | 代码路径、契约与故障分支按预期 | 真实站点可达、真实模型可用或效果 |
| 真实外网采集 | 当时真实 GET/模型调用可达，解析与校验按预期 | 长期稳定、覆盖完整或人工效果 |
| 真实服务器验证 | 隔离实例上的安装、部署、切换与回滚可行 | 公网放行或独立生产可用性 |
| 生产运行 | 线上实例的实际行为、连续运行与真实投递回执 | 人工评测效果或全部故障场景 |
| 人工评测 | 真人标注下的效果指标 | 样本量之外的泛化；不能单独证明系统整体效果 |

## 混类提醒

以下证据容易被读成比实际更强的结论：

- **M7 与 M10-A 的“通过”**：[M7 验收](archive/M7_RESULTS.md) 与 [M10-A 记录](archive/M10_RESULTS.md) 中的通过项是 Mock/合成数据或既有数据离线回放，不是真实模型效果；M7 真实模型请求为 0。
- **M9 服务器验收**：[M9 服务器验收](M9_SERVER_RESULTS.md) 是共享物理资源上的隔离实例与瞬时单元，不是独立生产验证；公网入口、真实域名证书与长期运行未在该阶段验收。
- **M10-C 本机表**：[M10-C 本机验收](M10C_RESULTS.md) 的 72 小时失效与复查积压通过项来自注入时钟推进 73 小时的模拟，不是真实长时运行；该文件另有三轮真实采集表，两者不能合并计为真实运行时间。
- **模拟与真实分开标注的范本**：[服务器连续运行验收](archive/M10C_SERVER_RESULTS_20261029.md) 把保留的历史通过/模拟项与真实连续运行分开写；引用时应沿用这种区分。
- **规范文件里的真实调用**：[分类与 LLM 复核](CLASSIFICATION_REVIEW.md) 是规范文件，但其 59–65 行夹有 2026-10-18 的真实付费调用证据（15 次请求、27,413 Token），不能把整份文件当作纯规范或纯验证。
- **M10-B 指标口径**：[人工与模型对照](M10B_LLM_RESULTS.md) 的指标来自 10 篇 development 标注，原文明确不能据此宣称整体分类准确率提高；独立 holdout 仍无真人真值。
